# BrowserManager

A Python Selenium project to manage multiple Firefox browser windows.

## Features

- Multiple Firefox browsers
- Threading
- Auto Restart
- Random Active Time
- Random Window Size
- Random Window Position
- Logging
- Configurable Settings

## Files

- manager.py
- browser_worker.py
- config.py
- logger.py

## Requirements

- Python 3.10+
- Selenium
- Firefox
- GeckoDriver (managed automatically by Selenium)
